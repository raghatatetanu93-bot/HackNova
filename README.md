# PromptShield

VORTEXA 3.0 hackathon project — C-03.

A middleware prototype that screens user prompts, documents,
and tool outputs for prompt injection and data exfiltration.

## Planned features
- Context-aware detection with local AI
- Allow, block, sanitize, or escalate decisions
- Editable security policies
- Evidence highlighting and decision history
- Evaluation of detections, misses, and false positives

## Team
Four members working on frontend, backend, AI, and evaluation.
